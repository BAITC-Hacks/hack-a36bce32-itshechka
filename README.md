# HackAlem AI — помощник по лекциям

Веб-прототип превращает расшифровку одной лекции в четыре учебных материала: конспект, основные тезисы, тест с правильными ответами и карточки для повторения.

## Структура

```text
frontend/  Create React App + React + Tailwind CSS v4 + Zustand
backend/   Python + FastAPI, авторизация и API приложения
ml/        изолированный AI pipeline (следующий этап)
```

Каждая глобальная папка независима. У фронтенда свой `package.json` и `node_modules`, у backend — собственное Python-окружение и `requirements.txt`.

## Что уже работает

- регистрация и вход по email/паролю;
- безопасное хеширование пароля через `scrypt`;
- JWT-сессия и защищённый endpoint профиля;
- маршруты `/login`, `/register` и защищённое рабочее пространство;
- базовая форма ввода лекции и секции будущих результатов;
- адаптивная оболочка на Tailwind CSS v4;
- healthcheck и автоматический тест полного auth-сценария.

AI-генерация пока намеренно не имитируется: интерфейс подготовлен, но кнопка обработки отключена до подключения настоящего pipeline.

## Запуск backend

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 4000
```

API будет доступен на `http://localhost:4000`, документация FastAPI — на `http://localhost:4000/docs`.

## Запуск frontend

В отдельном терминале:

```bash
cd frontend
npm install
npm start
```

Приложение откроется на `http://localhost:3000`. Команда `npm start` сначала компилирует Tailwind v4, затем запускает CSS watcher и стандартный `react-scripts start` от Create React App. Vite не используется.

## Переменные окружения

Скопируйте `.env.example` в `.env` в корне проекта и замените `JWT_SECRET` перед демонстрацией или публикацией.

```env
PORT=4000
CLIENT_ORIGIN=http://localhost:3000
JWT_SECRET=replace-with-a-long-random-string
JWT_EXPIRES_MINUTES=10080
```

Для другого адреса API создайте `frontend/.env`:

```env
REACT_APP_API_URL=http://localhost:4000/api
```

## План реализации ТЗ

1. Описать строгую JSON-схему результата: `summary`, `key_points`, `quiz`, `flashcards`, а каждому элементу добавить ссылки на фрагменты исходной лекции.
2. В `ml/` реализовать очистку и смысловое разбиение длинного текста, генерацию по частям и финальную агрегацию без внешних знаний.
3. Добавить проверку groundedness: каждый тезис и ответ должен подтверждаться цитируемым фрагментом; неподтверждённые элементы отбрасываются или перегенерируются.
4. В backend добавить сущности лекции и результата, endpoint обработки, состояния `queued/processing/completed/failed`, повторный запуск и понятные ошибки для пустого/короткого текста.
5. Во frontend реализовать состояния загрузки, вкладки четырёх материалов, интерактивный тест, переворачиваемые карточки и переход к сложным темам.
6. Подготовить выбранную контрольную лекцию, набор ожидаемых фактов и автоматическую/ручную оценку полноты, точности и отсутствия галлюцинаций.

## Текущие ограничения

- данные пользователей хранятся в локальном JSON-файле — для прототипа; перед production нужна БД;
- генерация материалов ещё не подключена;
- распознавание аудио/видео, чат и экспорт относятся к дополнительному объёму после выполнения основного сценария.
