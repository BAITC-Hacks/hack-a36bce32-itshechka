# ML service

Здесь будет изолирован AI pipeline: нормализация и разбиение лекции, генерация материалов по строгой JSON-схеме, проверка опоры на исходные фрагменты и оценка качества.

Публичный контракт этого слоя будет вызываться только backend-сервисом. На текущем этапе директория создана как архитектурная граница; модель и провайдер ещё не выбраны.
